# Sources — Utility Over-Earnings dataset (every value traceable)

Assembled from public sources, August 2026. Model assumptions (adjustable): risk-free rate 4.3% (FRED DGS10 — https://fred.stlouisfed.org/series/DGS10); equity risk premium 5.0%; **sector beta 0.24 = Damodaran (NYU Stern) 'Utility (General)', Jan 2026** (https://pages.stern.nyu.edu/~adamodar/New_Home_Page/datafile/Betas.html; broader 'Power' category = 0.48). Beta is applied uniformly to all utilities. Per-utility 'parent beta' is kept as a reference only and is NOT used in the calculation.
Risk-justified ROE (uniform) = 4.3% + 0.24 x 5.0% = 5.50%.
